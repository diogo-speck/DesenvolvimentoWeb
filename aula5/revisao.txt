1. HTML – ESTRUTURA BÁSICA
==============================================================

Estrutura mínima (ctrl + space):

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Título</title>
</head>
<body>
    Conteúdo
</body>
</html>

PRINCIPAIS ELEMENTOS
--------------------
<html>       raiz do documento.
<head>       metadados, título, CSS, scripts etc.
<body>       conteúdo visível.
<header>     cabeçalho.
<nav>        navegação.
<main>       conteúdo principal.
<section>    seção temática.
<footer>     rodapé.
<h1>...<h6> títulos.
<p>          parágrafo.
<a>          link.
<img>        imagem.
<ul>         lista não ordenada.
<ol>         lista ordenada.
<li>         item de lista.
<div>        contêiner genérico.
<span>       contêiner inline/genérico.
<table>      tabela.
<form>       formulário.

ATRIBUTOS IMPORTANTES
---------------------
id="..."        identifica UM elemento. Deve ser único na página.
class="..."     agrupa elementos para aplicar CSS/JS.
href="..."      destino de links.
src="..."       origem de imagens/scripts.
alt="..."       texto alternativo da imagem.
title="..."     informação auxiliar/tooltip.
name="..."      nome do campo enviado por formulário.
value="..."     valor de um input/botão.
required        torna o campo obrigatório.
placeholder     texto de orientação dentro do input.
min/max         limita valores numéricos.
type             define o tipo do input.

ID x CLASS
----------
id:
- identifica um elemento específico;
- JavaScript pode usar getElementById("id");
- CSS usa #id.

class:
- pode ser usada por vários elementos;
- CSS usa .classe;
- JavaScript pode selecionar vários elementos com querySelectorAll().

EXEMPLO:
<div id="posts" class="card-container"></div>

document.getElementById("posts")
document.querySelector(".card-container")

LINKS
-----
<a href="pagina.html">Página</a>
<a href="#secao">Ir para uma seção da mesma página</a>
<a href="https://exemplo.com">Site externo</a>

Para um link interno por âncora:
<section id="sobre">...</section>
<a href="#sobre">Sobre</a>

ATENÇÃO:
No projeto existem casos como id="#sobre". O padrão correto é:
id="sobre"
e:
href="#sobre"

Não se coloca # no valor do id.

IMAGENS
-------
<img src="imagem.jpg" alt="Descrição da imagem">

alt é importante para acessibilidade e também aparece quando a imagem não
pode ser carregada.

POST:

- normalmente usado para envio de dados.

3. CSS – CASCATA E SELETORES
==============================================================

CSS = Cascading Style Sheets.
Serve para definir aparência, layout e apresentação dos elementos HTML.

FORMA EXTERNA:
<link rel="stylesheet" href="css/global.css">

FORMA INTERNA:
<style>
    body {
        background-color: black;
    }
</style>

FORMA INLINE:
<p style="color:red">Texto</p>

Preferência geral: CSS externo, pois facilita organização e manutenção.

SELETORES
---------
Elemento:
p { ... }

Classe:
.card { ... }

ID:
#posts { ... }

Descendente:
.card img { ... }

Pseudo-classe:
button:hover { ... }

Pseudo-elemento:
#newChat::after { ... }

SELETORES IMPORTANTES
---------------------
*       todos os elementos
body    elemento body
.card   qualquer elemento com class="card"
#user   elemento com id="user"
.card img = imagens dentro de .card

BOX MODEL
---------
Todo elemento pode ser entendido como:

CONTENT
PADDING
BORDER
MARGIN

padding = espaço interno.
border  = borda.
margin  = espaço externo.

box-sizing: border-box;
faz width/height considerarem conteúdo + padding + border.

DISPLAY
-------
block:
- ocupa uma linha inteira por padrão.

inline:
- ocupa apenas o espaço necessário.

flex:
- cria um Flex Container.

none:
- remove o elemento do layout.

FLEXBOX
-------
display: flex;

flex-direction: row;
    itens em linha.

flex-direction: column;
    itens em coluna.

justify-content:
- controla o eixo principal.
- center, flex-start, flex-end, space-between etc.

align-items:
- controla o eixo transversal.

flex-wrap: wrap;
- permite quebrar os itens para outra linha.

gap:
- espaço entre os itens.

Exemplo usado nas galerias:
.gallery {
    display: flex;
    flex-direction: row;
    justify-content: center;
    flex-wrap: wrap;
    gap: 20px;
}

POSITION
--------
position: relative;
- mantém o elemento no fluxo e cria referência para filhos absolutos.

position: absolute;
- posiciona em relação ao ancestral posicionado.

position: fixed;
- fica fixo em relação à janela.

No clone do chat:
.card {
    position: relative;
}

.card-footer {
    position: absolute;
    bottom: 0;
}

CORES
-----
background-color: #fff;
color: #333;

RGB:
rgb(255, 0, 0)

RGBA:
rgba(0, 0, 0, 0.3)
O último valor é a transparência/opacidade.

VARIÁVEIS CSS
------------
:root {
    --cinza-1: #343541;
    --cinza-2: #202123;
}

Uso:
background: var(--cinza-1);

Vantagem: facilita reutilizar e alterar cores.

TAMANHOS
--------
px  = pixels.
%   = relativo ao elemento pai.
vw  = porcentagem da largura da viewport.
vh  = porcentagem da altura da viewport.
em  = relativo ao tamanho da fonte do elemento.
rem = relativo ao tamanho da fonte raiz.

RESPONSIVIDADE
--------------
Meta tag:
<meta name="viewport" content="width=device-width, initial-scale=1.0">

flex-wrap: wrap;
ajuda os elementos a quebrarem linha em telas menores.

7. DOM – DOCUMENT OBJECT MODEL
==============================================================

DOM representa o HTML como uma estrutura de objetos que o JavaScript pode
consultar e modificar.

SELECIONANDO ELEMENTOS
----------------------

Por ID:
document.getElementById("resultado");

Por seletor CSS:
document.querySelector(".card");

Vários elementos:

Por tag:
document.getElementsByTagName("p");

querySelector retorna o primeiro elemento que corresponde ao seletor.
querySelectorAll retorna uma NodeList com os elementos correspondentes.

------------------------
let valor = document.getElementById("cep").value;

element.innerHTML = "<strong>Olá</strong>";

innerText trata como texto.
innerHTML interpreta tags HTML.

CRIANDO ELEMENTOS
-----------------
const card = document.createElement("div");
card.className = "card";
card.innerHTML = "...";
cards.appendChild(card);

createElement cria um elemento.
appendChild adiciona o elemento como filho.

ATRIBUTOS
---------
elemento.id
elemento.className
elemento.value
elemento.src

Também:

8. EVENTOS
==============================================================

Eventos são ações ocorridas no navegador.

Exemplos:
click
submit
change
input
DOMContentLoaded
mouseover
keydown

INLINE
------
<button onclick="consultarCEP()">Consultar</button>

O código do projeto utiliza bastante onclick.

ADDEVENTLISTENER
----------------
document.addEventListener("DOMContentLoaded", getPosts);

Significa:
quando o HTML terminar de ser carregado, execute getPosts.

Outro exemplo:
element.addEventListener("click", () => {
    ...
});

Vantagem:
separa o JavaScript do HTML.

SUBMIT
------
Um formulário dispara o evento submit.

Para impedir o comportamento padrão:
event.preventDefault();

Exemplo:
form.addEventListener("submit", (event) => {
    event.preventDefault();
    ...
});

IMPORTANTE SOBRE O PROJETO:
Há casos como:
<input type="submit" onclick="...">

e casos em que aparece onsubmit no input. O evento submit pertence ao
FORM, não ao botão. O padrão correto é tratar o submit no <form> ou usar
onclick no botão quando a intenção for apenas tratar o clique.

==============================================================
9. PROPAGAÇÃO DE EVENTOS
==============================================================

Um evento pode se propagar pela árvore DOM.

BUBBLING:
- o evento começa no elemento mais interno;
- depois sobe para os elementos pais.

CAPTURING:
- o evento percorre os pais em direção ao alvo antes de chegar nele.

event.target:
- elemento que realmente originou o evento.

event.currentTarget:
- elemento no qual o listener está sendo executado.

Para interromper propagação:
event.stopPropagation();

12. JSON
==============================================================

JSON = JavaScript Object Notation.

É um formato textual muito usado para trocar dados entre aplicações e APIs.

Objeto JS:
const pessoa = {
    nome: "Ana",
    idade: 20
};

Converter objeto para JSON:
JSON.stringify(pessoa);

Converter JSON para objeto:
JSON.parse(texto);

EXEMPLO:
localStorage.setItem("dados", JSON.stringify(dados));

Depois:
const dados = JSON.parse(localStorage.getItem("dados"));

IMPORTANTE:
localStorage/sessionStorage armazenam strings.
Por isso objetos precisam de JSON.stringify().
Ao recuperar, usa-se JSON.parse().

==============================================================
13. LOCALSTORAGE E SESSIONSTORAGE
==============================================================

localStorage:
- mantém os dados mesmo depois de fechar o navegador;
- permanece até ser removido.

sessionStorage:
- mantém os dados durante a sessão/aba;
- normalmente é encerrado quando a sessão da aba termina.

MÉTODOS
-------
setItem:
localStorage.setItem("chave", "valor");

getItem:
localStorage.getItem("chave");

removeItem:
localStorage.removeItem("chave");

clear:
localStorage.clear();

Mesmos métodos para sessionStorage.

PROJETO AULA 4
--------------
Endereço:
const endereco = {
    rua: ...,
    cidade: ...,
    estado: ...,
    cep: ...
};

sessionStorage.setItem(
    "endereco",
    JSON.stringify(endereco)
);

Recuperação:
let endereco = JSON.parse(
    sessionStorage.getItem("endereco")
);

PROJETO AULA 5
--------------
Objeto inicial:
let dados = JSON.parse(localStorage.getItem("dados")) || {
    tipo: null,
    dataehora: null,
    local: null,
    envolvidos: null,
    objetos: null,
    relato: null,
    aceita: false
};

O operador || significa:
se o primeiro valor for falsy, utiliza o segundo.

saveData:
function saveData(elemento, atributo){
    dados[atributo] = elemento;
    localStorage.setItem("dados", JSON.stringify(dados));
}

Isso:
1. altera uma propriedade do objeto;
2. transforma o objeto em JSON;
3. salva no localStorage.

15. FETCH API
==============================================================

fetch() faz requisições HTTP e retorna uma Promise.

Exemplo:
fetch("https://exemplo.com/api")
    .then(response => response.json())
    .then(data => {
        console.log(data);
    })
    .catch(error => {
        console.error(error);
    });

FLUXO:
fetch()
  ↓
Promise<Response>
  ↓
response.json()
  ↓
Promise com dados JavaScript
  ↓
.then(data => ...)

response.json() também é assíncrono.

TRATAMENTO DE ERRO
------------------
.catch(error => {
    console.error(error);
});

==============================================================
16. PROMISES E .THEN()
==============================================================

Promise representa o resultado futuro de uma operação assíncrona.

Estados:
- pending
- fulfilled
- rejected

.then() executa quando a Promise é resolvida.

.catch() trata rejeição/erro.

Exemplo:
fetch(url)
    .then(response => response.json())
    .then(data => console.log(data))
    .catch(error => console.log(error));

Também existe async/await:

async function carregar() {
    try {
        const response = await fetch(url);
        const data = await response.json();
        console.log(data);
    } catch (error) {
        console.error(error);
    }
}

17. API E REST
==============================================================

API = Application Programming Interface.

Permite que um sistema converse com outro.

Exemplo do projeto:
ViaCEP
https://viacep.com.br/ws/CEP/json/

O JavaScript envia uma requisição e recebe dados JSON.

REST é um estilo arquitetural muito utilizado para APIs HTTP.

MÉTODOS HTTP
------------
GET     buscar dados.
POST    criar/enviar dados.
PUT     atualizar recurso inteiro.
PATCH   atualizar parcialmente.
DELETE  remover recurso.

STATUS HTTP COMUNS
------------------
200 OK
201 Created
400 Bad Request
401 Unauthorized
403 Forbidden
404 Not Found
500 Internal Server Error

IMPORTANTE:
fetch() não necessariamente rejeita a Promise apenas porque o servidor
retornou 404/500. Para verificar isso:

if (!response.ok) {
    throw new Error("Erro HTTP: " + response.status);
}

23. BOAS PRÁTICAS COM FETCH
==============================================================

Estrutura recomendada:

fetch(url)
    .then(response => {
        if (!response.ok) {
            throw new Error(`HTTP ${response.status}`);
        }
        return response.json();
    })
    .then(data => {
        // usar dados
    })
    .catch(error => {
        // tratar erro
    });

Ou async/await com try/catch.

Sempre considerar:
- conexão pode falhar;
- API pode retornar erro;
- JSON pode estar inválido;
- dados podem não existir;
- resposta pode não possuir o campo esperado.

27. CUIDADO COM sessionStorage NO PROJETO
==============================================================

Existe uma inconsistência no arquivo endereco.js.

Se salvar um objeto inteiro em uma chave, depois recupere a mesma chave e

31. ERROS IMPORTANTES ENCONTRADOS NO PROJETO
==============================================================

1) querySelectorAll retorna vários elementos.

Exemplo problemático:
const elementos = document.querySelectorAll("seletor");
elementos.addEventListener(...);

NodeList não possui addEventListener diretamente.

Para cada elemento:
elementos.forEach(elemento => {
    elemento.addEventListener("click", ...);
});

Ou, se só existe um elemento, use querySelector().

2) Seletor inválido/sem elemento:
document.querySelectorAll("sdnfdfmg")

Se a intenção era selecionar uma classe, deveria ser:
document.querySelectorAll(".classe")

Se era um id:
document.querySelectorAll("#id")

3) IDs com #:
id="text" está correto.
querySelector("#text") usa #.
Não:
id="#text"

4) onsubmit no input:
O submit pertence ao formulário.
Preferível:
<form onsubmit="...">
ou addEventListener("submit", ...)

5) Variável não definida:
onclick="saveData(relato, 'relato')"

Se "relato" não for uma variável contendo o valor, haverá erro.
Normalmente:
document.getElementById("text").value

6) submit pode recarregar/trocar a página.
Para impedir:
event.preventDefault();

7) <spam> usado no projeto.
A tag HTML correta provavelmente seria <span>.
<spam> não é a tag semântica padrão para esse uso.

8) Atributo id duplicado:
<footer id="inscricao" id="#inscricao">

Um elemento não deve ter dois atributos id.
Correto:
<footer id="inscricao">

9) Âncoras:
id="#inscricao" está errado.
Correto:
id="inscricao"
e:
href="#inscricao"

10) Links sem aspas:
<a href=index.html>
Funciona em muitos casos, mas a forma correta é:
<a href="index.html">

11) HTML antigo:
<font>, bgcolor etc. aparecem nos arquivos antigos.
Atualmente, apresentação deve ser feita com CSS.

12) console.log:
É ótimo para depuração, mas não substitui mostrar o resultado na interface.

32. DIFERENÇA ENTRE .VALUE E .INNERHTML/.INNERTEXT

Para elemento HTML:

ou:
document.getElementById("resultado").innerHTML

Exemplo:

Já:

REGRA PRÁTICA:

elemento visual -> .innerText ou .innerHTML

==============================================================
33. innerText x innerHTML
==============================================================

innerText:
element.innerText = "<b>Olá</b>";

Mostra literalmente:
<b>Olá</b>

innerHTML:
element.innerHTML = "<b>Olá</b>";

Interpreta a tag e deixa "Olá" em negrito.

Cuidado com innerHTML quando dados externos não são confiáveis, pois inserir
HTML diretamente pode causar problemas de segurança (XSS).

==============================================================

parseFloat("10.50") -> 10.5

No projeto:

Para preços:

Também existe:
Number("10.5")

42. CASCATA E ESPECIFICIDADE
==============================================================

Quando várias regras CSS afetam o mesmo elemento, entram em jogo:
- importância;
- especificidade;
- ordem das regras.

De forma simplificada:
inline > id > class/pseudo-class/atributo > elemento

Exemplo:
#titulo { color: red; }
.titulo { color: blue; }

Se o elemento tiver id="titulo" e class="titulo", a regra do id normalmente
tem maior especificidade.

Evite usar !important sem necessidade.

45. EXEMPLO COMPLETO – API + DOM

const carregar = function () {

    fetch("https://exemplo.com/api")
        .then(response => {

            if (!response.ok) {
                throw new Error("Erro HTTP: " + response.status);
            }

            return response.json();
        })
        .then(dados => {

            const container =
                document.getElementById("posts");

            dados.forEach(item => {

                const card =
                    document.createElement("div");

                card.className = "card";

                card.innerHTML = `
                    <h2>${item.title}</h2>
                    <p>${item.body}</p>
                `;

                container.appendChild(card);
            });
        })
        .catch(error => {
            console.error(error);
        });
};

document.addEventListener(
    "DOMContentLoaded",
    carregar
);
